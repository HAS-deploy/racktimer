## Full new description (paste this into ASC en-US description field for the new draft version)

RackTimer is the gym-side utility for lifters who already know what they're doing.

Fast rest timer. Instant plate calculator. Previous-set recall. Simple templates. No spreadsheet, no social feed, no trainer marketplace.

Features
• Rest timer — one-tap presets (60 / 90 / 120 / 180s), pause, resume, restart, optional auto-restart
• Rest timer notifications fire reliably even when the app is backgrounded or the screen is off
• Plate calculator — target weight, bar weight, per-side plate math in lb or kg
• Previous-set recall — see last weight, reps, and note for any exercise
• Quick logging — exercise, weight, reps, note — done
• Templates — push, pull, legs, upper, lower — or roll your own
• History — chronological view of everything you've lifted

Privacy-first
• No account, no sign-in
• No cloud sync · anonymous, opt-out product analytics only

Pricing
• Free forever: rest timer, plate calculator, 3 saved templates, 14 days of history
• Premium Monthly — $2.99/month (auto-renewing): unlimited templates, unlimited history, previous-set recall across every exercise, custom plate inventory, advanced timer presets
• Premium Yearly — $19.99/year (auto-renewing) with a 14-day free trial: the same premium features, billed annually
• Premium Lifetime — $14.99 (one-time): the same premium features, paid once, kept forever

Pick yearly with a 14-day free trial, monthly to try premium month-to-month, or lifetime to unlock everything with a single purchase.
