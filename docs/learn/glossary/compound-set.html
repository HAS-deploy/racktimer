compound set — strength-training glossary

What it means

A compound set is two exercises performed back-to-back for the same muscle group, with little to no rest between them. You complete a set of the first exercise, immediately move into a set of the second exercise targeting the same muscles, and then rest before repeating the pairing. The goal is to drive more total volume and fatigue into a specific muscle in a shorter time window.

Why it matters

Compound sets show up most often in hypertrophy-focused training when you want to thoroughly exhaust a muscle group without spending extra time in the gym. A common use case is pairing a heavy compound movement with an isolation exercise for the same muscle — for example, bench press followed immediately by a dumbbell fly. The compound lift handles heavier loading while the isolation movement finishes off the muscle when it's already fatigued. This technique is also used by lifters who are short on time but still want meaningful training volume per session.

Example

You do 8 reps of barbell curls, then without resting you do 10 reps of incline dumbbell curls. After both sets are done, you rest 90 seconds and repeat. Both exercises target the biceps — that pairing is a compound set.

Common confusions

Compound set vs. superset: This is the most frequent mix-up. A superset pairs two exercises for opposing or different muscle groups (e.g., biceps curl + triceps pushdown), while a compound set targets the same muscle group twice. Some people use "superset" loosely to mean any back-to-back pairing, which adds to the confusion — but technically they are distinct.

Compound set vs. "compound exercise": The word "compound" appears in both terms but means something different each time. A compound exercise (like a squat or deadlift) is a movement that recruits multiple joints and muscle groups. A compound set is a training structure about how you sequence your sets. You can do a compound set using isolation exercises; the name has nothing to do with whether the movements themselves are compound lifts.

Compound set vs. drop set: A drop set involves reducing the weight on the same exercise and continuing without rest. A compound set switches to a different exercise. Both create extended fatigue in a muscle, but the mechanics are different.
